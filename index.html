УСТАНОВКА ЗА 5 ШАГОВ

1

Установи Python

Скачай с python.org. При установке поставь галочку «Add to PATH».

python.org → Download
2

Установи Ollama

Скачай с ollama.com. Нужна для текстовых моделей.

ollama.com → Download
3

Скачай anticloud2.py

Нажми кнопку ниже — файл скачается.

4

Установи библиотеки

Открой PowerShell и выполни:

pip install customtkinter pillow ollama diffusers transformers accelerate safetensors imageio[ffmpeg] imageio-ffmpeg
5

Запусти

В той же PowerShell:

cd C:\Users\ТвоёИмя python anticloud2.py
